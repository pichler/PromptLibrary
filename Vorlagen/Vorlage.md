# Titel des Prompts

> Kurzbeschreibung in einem Satz: Was macht dieser Prompt und was kommt dabei heraus?

| | |
|---|---|
| **Kategorie** | z. B. LinkedIn, Recherche, E-Mail, Analyse |
| **Getestet mit** | z. B. Claude, ChatGPT, Gemini |
| **Sprache** | Deutsch |
| **Version** | 1.0 |
| **Zuletzt getestet** | TT.MM.JJJJ |

---

## Zweck

Beschreibe in zwei bis drei Sätzen, wofür der Prompt gedacht ist und welches Problem er löst.

**Gut geeignet für:**
- Anwendungsfall 1
- Anwendungsfall 2

**Weniger geeignet für:**
- Grenzfall oder Gegenbeispiel

---

## Prompt

Zum Kopieren auf das Kopiersymbol rechts oben im Codeblock klicken. Die Platzhalter in `{{doppelten geschweiften Klammern}}` vor dem Einsetzen ersetzen.

```text
Du bist {{Rolle, z. B. erfahrener Texter für LinkedIn}}.

Aufgabe:
{{Was soll erledigt werden?}}

Kontext:
{{Hintergrundinformationen, Zielgruppe, Ziel}}

Vorgaben:
- {{Tonalität, z. B. sachlich, persönlich}}
- {{Länge, z. B. maximal 1.200 Zeichen}}
- {{Format, z. B. Fließtext ohne Aufzählungen}}

Eingabe:
{{Text, Stichpunkte oder Daten, die verarbeitet werden sollen}}
```

---

## Variablen

| Platzhalter | Bedeutung | Beispiel |
|---|---|---|
| `{{Rolle}}` | Welche Rolle das Modell einnimmt | Erfahrener Texter für LinkedIn |
| `{{Aufgabe}}` | Was erledigt werden soll | Einen Post über ein Projekt schreiben |
| `{{Kontext}}` | Hintergrund und Zielgruppe | Zielgruppe: Fachleute aus der Industrie |
| `{{Eingabe}}` | Das Ausgangsmaterial | Stichpunkte zum Projekt |
